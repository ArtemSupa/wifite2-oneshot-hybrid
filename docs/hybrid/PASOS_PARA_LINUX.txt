╔══════════════════════════════════════════════════════════════════════════╗
║                          PARTE 1: EN WINDOWS                             ║
╚══════════════════════════════════════════════════════════════════════════╝

OPCIÓN A: Comprimir Automáticamente (RECOMENDADO)
────────────────────────────────────────────────────────────────────────────
1. Ejecutar:
   compress_for_linux.bat

2. Se creará:
   wifite-oneshot-hybrid.tar.gz  (o .zip)

3. Copiar este archivo a:
   - USB
   - Transferir por SCP
   - Subir a GitHub/GitLab (privado)


OPCIÓN B: Comprimir Manualmente
────────────────────────────────────────────────────────────────────────────
1. Abrir Git Bash en: D:\Development\

2. Ejecutar:
   tar -czf wifite-hybrid.tar.gz "hibrido hack"

3. El archivo wifite-hybrid.tar.gz está listo para transferir


╔══════════════════════════════════════════════════════════════════════════╗
║                      PARTE 2: TRANSFERIR A KALI                          ║
╚══════════════════════════════════════════════════════════════════════════╝

OPCIÓN A: Usando USB
────────────────────────────────────────────────────────────────────────────
1. Copiar wifite-hybrid.tar.gz al USB

2. En Kali, insertar USB y montar:
   lsblk
   sudo mount /dev/sdb1 /mnt  (ajustar sdb1 según tu USB)
   cp /mnt/wifite-hybrid.tar.gz ~/
   sudo umount /mnt


OPCIÓN B: Usando SCP (si Kali tiene SSH activo)
────────────────────────────────────────────────────────────────────────────
En Windows (Git Bash o CMD):
   scp wifite-hybrid.tar.gz kali@192.168.1.100:~/

   (Reemplazar 192.168.1.100 con la IP de tu Kali)


OPCIÓN C: Usando Git (MEJOR para actualizaciones futuras)
────────────────────────────────────────────────────────────────────────────
1. En Windows:
   cd "D:\Development\hibrido hack"
   git init
   git add .
   git commit -m "Wifite + OneShot hybrid"
   git remote add origin https://github.com/tuusuario/tu-repo.git
   git push -u origin main

2. En Kali:
   git clone https://github.com/tuusuario/tu-repo.git
   cd tu-repo


╔══════════════════════════════════════════════════════════════════════════╗
║                    PARTE 3: INSTALAR EN KALI                             ║
╚══════════════════════════════════════════════════════════════════════════╝

1. Descomprimir:
   cd ~
   tar -xzf wifite-hybrid.tar.gz
   cd wifite-oneshot-hybrid

2. Dar permisos de ejecución:
   chmod +x install_linux.sh

3. Ejecutar instalador:
   sudo ./install_linux.sh

   Esto instalará:
   - Dependencias del sistema
   - Python 3.8+ (si no está)
   - Creará el comando: wifite-hybrid


╔══════════════════════════════════════════════════════════════════════════╗
║                      PARTE 4: USAR EN KALI                               ║
╚══════════════════════════════════════════════════════════════════════════╝

1. Poner interfaz en modo monitor:
   sudo airmon-ng check kill
   sudo airmon-ng start wlan0

2. Ejecutar wifite híbrido:
   sudo wifite-hybrid -i wlan0mon --wps

   ¡El híbrido se activará automáticamente cuando detecte M6!


3. Comandos disponibles:
   wifite-hybrid          → Tu versión modificada (con OneShot)
   wifite                 → Versión original de Kali (si no la desinstalaste)

╔══════════════════════════════════════════════════════════════════════════╗
║                        TROUBLESHOOTING                                   ║
╚══════════════════════════════════════════════════════════════════════════╝

PROBLEMA: "wifite-hybrid: command not found"
SOLUCIÓN:
   sudo ln -s /opt/wifite-hybrid/wifite2/wifite.py /usr/local/bin/wifite-hybrid
   sudo chmod +x /usr/local/bin/wifite-hybrid


PROBLEMA: "ModuleNotFoundError: No module named..."
SOLUCIÓN:
   cd /opt/wifite-hybrid/wifite2
   sudo pip3 install -r requirements.txt


PROBLEMA: "oneshot.py not found"
SOLUCIÓN:
   cd /opt/wifite-hybrid
   python3 test_oneshot_path.py
   (Verificar que OneShot esté en la ruta correcta)


PROBLEMA: "Permission denied"
SOLUCIÓN:
   sudo wifite-hybrid ...
   (Siempre ejecutar con sudo en Linux)


PROBLEMA: "Interface not found"
SOLUCIÓN:
   sudo airmon-ng check kill
   sudo airmon-ng start wlan0
   (Reemplazar wlan0 con tu interfaz)
